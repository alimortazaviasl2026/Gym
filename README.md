# 🏋️ Gym Landing Page

A modern and responsive gym landing page built with **React**, **HTML**, **CSS**, **JavaScript**, and **Bootstrap**.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Modern gym landing page UI
- Hero section with call-to-action button
- Services and training sections
- About gym section
- Membership plans section
- Contact section
- Clean and reusable React components

## 🛠️ Technologies Used

- React.js
- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
